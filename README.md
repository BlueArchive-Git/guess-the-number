## 这是什么？
这是一个使用 **Rust 语言** 编写的猜数字游戏程序示例，也可以当作一个用来消遣的小玩具。

## 怎么装？
确保你的环境安装了 rust：

```bash
rustc --version
cargo --version
```

克隆本仓库：

```bash
git clone https://github.com/BlueArchive-Git/guess-the-number.git
cd guess-the-number
```

编译 & 安装：

```bash
cargo run
cargo build
cargo install
```

随后按照提示将 $HOME/.cargo/bin 加入 PATH 环境变量即可。

## 怎么用？
直接输入 `gtn` 即可启动：

```bash
gtn
```

根据提示来输入不同的数字即可。
